# Luna Task Card

```text
角色：Luna 执行
目标：完成一个可独立验收的具体结果
范围：允许读取和修改的文件/目录
输入：当前阶段必需信息和前置产物
验收：命令、输出格式和行为标准
并行任务：任务标识、独立输入/输出/写入范围和依赖（如适用）
约束：不得越界、提交、发布、处理密钥或生成备份/临时残留
回报：修改文件、测试命令与结果、错误日志、产物、风险、未完成项
```

并行任务最多 3 个；只有输入、输出、写入范围和依赖均不重叠时才可并行。每个并行任务必须单独派卡并设置闸门，不得共享文件或生成物写入。Luna 回报后立即停止，不自行推进下一阶段。

Sol 对真实运行中的子任务持续等待到 `completed`、`failed`、`timed_out` 或 `needs_user_input`；正常等待不是 stalled。并行组的全部任务结束并经 Sol 独立验收后才能统一输出；任一失败、超时、缺少关键产物或需用户输入时，整体未完成并锁定依赖阶段。
