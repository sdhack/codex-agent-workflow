# Stage Gates

默认 DAG 为：探索 → 实施 → 验证 → Sol 验收。审查是按需安排的可选阶段，不自动插入默认 DAG。

| 阶段 | 执行者 | 输出 | 放行条件 |
|---|---|---|---|
| 探索 | luna_scout | 文件、依赖、测试和风险摘要 | 范围与依赖明确 |
| 实施 | luna_worker | 受限 diff | 只改允许文件 |
| 验证 | luna_tester | 命令、日志、产物 | 无错误且关键行为通过 |
| 可选审查 | luna_critic | 风险和缺口 | Sol 明确安排且无阻断问题 |
| 验收 | Sol | 最终结果 | Sol 独立复核实际证据 |

当子任务正在执行命令、安装、编译、测试或等待外部进程时，Sol 必须等待至 `completed`、`failed`、`timed_out` 或 `needs_user_input`。无新输出的正常等待不判作 stalled。

只有输入、输出、写入范围和依赖均独立的任务才允许并行，最多 3 个；每个并行任务必须有独立任务卡和闸门。所有并行任务结束且 Sol 独立验收后才能统一输出。任一失败、超时、关键产物缺失或需要用户输入，整体判定未完成并锁定依赖阶段。

异常、错误日志、失败重试未收口、产物数量矛盾、关键文件缺失、密钥或残留文件均判定失败。
